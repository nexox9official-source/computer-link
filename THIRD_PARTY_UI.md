# Third-party UI references and adapted code

LinkOS uses and adapts UI ideas/code patterns from the following MIT-licensed
ComputerCraft projects.

## OneOS

Source: https://github.com/oeed/OneOS

Copyright Oliver Cooper 2015

MIT License. LinkOS 0.22 adapts the compact application-card layout and
collection layout concepts from OneOS App Store objects (AppView,
AppCollectionView and AppDetailsView). The original license permits use,
copying and modification with preservation of the copyright/license notice.

## Opus OS

Source: https://github.com/kepler155c/opus

Copyright (c) 2016-2019 kepler155c

MIT License. LinkOS 0.22 adapts component-state patterns from Opus UI,
including focused/inactive buttons, tab selection and scrolling-list behavior.

## Basalt

Source: https://github.com/Pyroxenium/Basalt

Copyright (c) 2022 Robert Jelic

MIT License. Basalt is used as a design reference for component/event/theme
architecture. LinkOS does not currently vendor the full Basalt runtime.

All three projects retain their original copyright. Their MIT licenses permit
use, copying, modification, merge and redistribution provided the copyright and
permission notices are included.

LevelOS is used only as a visual/UX reference; no LevelOS source code is copied
into LinkOS unless a compatible license is independently verified.
