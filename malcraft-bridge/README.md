# Malcraft Bridge

Server-only Forge 1.20.1 addon for the fictional Malcraft gameplay system.

It injects a `malcraft_bus` API into every CC:Tweaked computer. The bus is entirely internal to the Minecraft server and allows Malcraft-infected Computers to register, persist by Computer ID, exchange commands and publish their in-game terminal screen without requiring a physical modem.

It does not access the player's real computer, operating-system files, LAN, internet devices or anything outside Minecraft/CC:Tweaked.
